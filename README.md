# Bulk Water Infrastructure Benchmarking Study

**Date:** January 2026
**Version:** 1.0

## Overview

This repository contains a comprehensive benchmarking study of bulk water supply pipeline infrastructure projects in Australia, with a focus on Queensland. The study examines projects with construction completed or substantially commenced between 2019-2025.

## Scope Definition

**Included:**
- Large-diameter pipelines (≥300mm) for bulk water supply
- Dam-to-treatment, scheme interconnections, regional supply pipelines
- Municipal and agricultural supply infrastructure

**Excluded:**
- Urban reticulation networks
- Recycled water systems
- Stormwater infrastructure
- Desalination plant internal pipework

## Key Findings

| Metric | Value |
|--------|-------|
| **Sample Size** | 4 core projects + 2 supplementary |
| **Total Pipeline Length** | 436 km |
| **Cost Range** | $3.5M - $14.3M per kilometre |

## Benchmarking Guidance

### Cost Ranges by Diameter (AUD 2024)

| Diameter Class | Low | Mid | High |
|----------------|-----|-----|------|
| Medium (450-750mm) | $4.0M/km | $5.5M/km | $7.5M/km |
| Large (750-1200mm) | $7.0M/km | $9.0M/km | $12.0M/km |
| Very Large (>1200mm) | $8.0M/km | $10.0M/km | $15.0M/km |

### Key Adjustment Factors

| Factor | Adjustment |
|--------|------------|
| Greenfield terrain | +20-40% |
| Hilly terrain | +15-30% |
| Treatment plant inclusion | +5-15% |
| Remote location | +10-25% |

## Limitations

- Small sample size (n=4-6)
- Geographic concentration (QLD/VIC)
- Exceptional cost volatility during study period (2019-2024)
- Limited cost breakdown data available

## Appropriate Use

| Use Case | Suitability |
|----------|-------------|
| Early project scoping | Appropriate |
| Order-of-magnitude estimates | Appropriate |
| Business case reasonableness | Appropriate |

| Tender evaluation | Not recommended |
