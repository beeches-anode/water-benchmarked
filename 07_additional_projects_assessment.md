# Potential Additional Projects Assessment
## Bulk Water Pipeline Benchmarking Database Expansion

**Assessment Date:** January 2026
**Purpose:** Evaluate additional projects for inclusion in benchmarking database

---

## Assessment Criteria

Projects are assessed on their **usefulness** for improving pipeline cost estimation capability:

| Criterion | Weight | Description |
|-----------|--------|-------------|
| Scope Alignment | 30% | Does the project meet bulk water pipeline criteria (≥300mm, municipal/agricultural)? |
| Data Quality | 25% | How complete and verifiable is cost/specification data? |
| Comparability | 20% | How comparable is the project to typical new pipeline projects? |
| Construction Window | 15% | Is it within the 2019-2025 timeframe? |
| Geographic Value | 10% | Does it add regional diversity to the sample? |

**Usefulness Score:** 0-100%

## CONCLUSION

**Top 4 projects recommended for immediate inclusion:**

1. **Mount Morgan Pipeline** - Best available data for small-medium diameter regional supply
2. **South West Pipeline** - Completed SEQ grid project with verified cost
3. **Manton Dam Pipeline** - Critical NT coverage, well-specified
4. **Yan Yean-Bald Hill Pipeline** - Large diameter urban, if cost obtainable

These additions would:
- Double the core sample size from 4 to 8 projects
- Add 2 new states (NT, TAS) to geographic coverage
- Provide 3 additional completed project costs
- Significantly improve medium-diameter (300-600mm) benchmarking capability

**Overall recommendation:** Pursue data collection for high-priority projects to strengthen the benchmarking database before the next major project cost estimate requirement.
