# SLIDE 1: Purpose and Methodology

## Bulk Water Pipeline Cost Benchmarking
### Establishing Evidence-Based Cost Guidance for Infrastructure Planning

**Purpose**
- Develop defensible cost benchmarks for bulk water supply pipelines
- Support early-stage project scoping and business case development
- Enable reasonableness testing of cost estimates

**Methodology**
1. Comprehensive research of Australian bulk water pipeline projects (2019-2025)
2. Data collection from government announcements, budget papers, and official sources
3. Normalisation of costs to AUD 2024 using ABS construction cost indices
4. Statistical analysis and cost driver identification
5. Independent self-audit of research and analysis

**Scope Definition**
- Large-diameter pipelines (≥300mm) for municipal/agricultural bulk water supply
- Dam-to-treatment, scheme interconnections, regional supply
- Queensland, Victoria, Northern Territory coverage
- Excludes: urban reticulation, recycled water, desalination internal pipework

# SLIDE 4: Cost Driver Insights (Enhanced)

## What Drives Bulk Water Pipeline Costs?

### Primary Cost Drivers (Ranked by Impact)

```
COST IMPACT SCALE
|========================================| 100%
|                                        |
|  1. DIAMETER                           |
|  [==============================]  60% |
|  Larger pipes = higher costs           |
|  +$2-4M/km per 500mm increase          |
|                                        |
|  2. TERRAIN / ACCESS                   |
|  [======================]  40%         |
|  Greenfield: +25-45% premium           |
|  Steep gradient: +20-35%               |
|  Mountainous: +15-25%                  |
|                                        |
|  3. COMPLEXITY FEATURES                |
|  [================]  30%               |
|  Tunnelling: +15-30%                   |
|  River crossings (3+): +10-20%         |
|                                        |
|  4. SCOPE INCLUSIONS                   |
|  [============]  20%                   |
|  Treatment plants, reservoirs          |
|  Pump stations: +$0.5-1.5M/km          |
|                                        |
|  5. MARKET CONDITIONS                  |
|  [==========]  15%                     |
|  2020-24 escalation: 25%+              |
|  Labour & materials volatility         |
|========================================|
```

### Case Studies: Terrain and Complexity Impact

**Haughton Pipeline Comparison (Same 1,800mm Diameter)**

| Stage | Terrain | $/km | Difference |
|-------|---------|------|------------|
| Stage 1 | Existing corridor | $8.2M | Baseline |
| Stage 2 | Greenfield (new access) | $12.2-14.3M | **+48-74%** |

**New v2.0 Insights:**

| Factor | Project | $/km | Premium vs Base |
|--------|---------|------|-----------------|
| **Steep gradient (29%)** | Yan Yean-Bald Hill | $10.0M | +25% vs similar diameter |
| **Mountainous terrain** | Mount Morgan | $3.15M | +10-15% (includes reservoirs) |
| **4 river crossings** | South West Pipeline | $3.52M | +10-15% crossing premium |
| **Remote NT** | Manton Dam | $2.50M | Lower than expected |

**Key Insight:** Terrain complexity can increase costs by 25-75%, independent of pipeline size.

# SLIDE 5: Benchmarking Guidance for New Projects (Updated)

## Recommended Cost Estimating Framework

### Step 1: Select Base Rate by Diameter

| Diameter | Base Rate ($/km) |
|----------|------------------|
| 300-450mm | $3.5M |
| 450-750mm | $4.5M |
| 750-1200mm | $9.0M |
| >1200mm | $11.0M |

### Step 2: Apply Adjustment Factors

| Factor | Adjustment | Evidence |
|--------|------------|----------|
| **Terrain** | | |
| Existing corridor / flat | -15% | HP1 |
| Rolling rural (base) | 0% | SWP, TWP |
| Mountainous | +20% | MMP |
| Steep gradient (>20%) | +25% | YYB |
| Greenfield (new access) | +35% | HP2 |
| **Complexity** | | |
| Tunnelling required | +20% | YYB |
| 3+ river crossings | +15% | SWP |
| **Scope** | | |
| Pipeline only (base) | 0% | SWP, MDP |
| Including pump stations | +10% | Multiple |
| Including treatment plant | +10% | FGP |
| Including reservoirs | +$2-4M each | MMP |
| **Location** | | |
| Major regional (base) | 0% | SWP, TWP |
| Remote regional | +10% | MDP |
| Urban fringe | +15% | YYB |

### Step 3: Add Allowances

| Allowance | Rate |
|-----------|------|
| Development costs | 8% of construction |
| Contingency | **25-30% minimum** |
| Escalation (if multi-year) | 5% per year |

### Example Calculation

**Scenario:** 50km pipeline, 600mm diameter, hilly terrain, regional location

| Component | Calculation | Amount |
|-----------|-------------|--------|
| Base rate | 50km x $4.5M | $225M |
| Terrain (+20%) | $225M x 1.20 | $270M |
| Development (8%) | $270M x 1.08 | $292M |
| Contingency (27.5%) | $292M x 1.275 | **$372M** |

# SLIDE 9: Summary and Key Takeaways

## Bulk Water Pipeline Benchmarking: Key Messages

### What We Found

```
+----------------------------------------------------------+
|                                                          |
|  COST RANGE: $2.5M - $14.3M per kilometre               |
|              (AUD 2024, bulk municipal supply)           |
|                                                          |
|  MEDIAN:     $6.1M per kilometre (8-project sample)     |
|                                                          |
|  KEY DRIVERS:                                            |
|  1. Diameter is primary determinant                      |
|  2. Terrain/access is significant secondary driver       |
|  3. Tunnelling and complexity add 15-30%                 |
|                                                          |
|  CONFIDENCE: IMPROVED from v1.0                          |
|  - Sample doubled from 4 to 8 core projects             |
|  - Added NT coverage (first interstate non-VIC)          |
|  - Medium diameter data significantly improved           |
|                                                          |
|  CAUTION:    25-30% contingency essential               |
|              (35-45% for complex/long duration)          |
|                                                          |
+----------------------------------------------------------+
```

### How to Use This Data

| Do | Don't |
|----|-------|
| Use for early scoping | Rely on for tender prices |
| Apply adjustment factors for terrain/scope | Use single point estimates |
| Include adequate contingency (25-30%) | Ignore terrain complexity |
| Reference evidence projects for adjustments | Extrapolate beyond sample |
| Update as new data available | Treat as static benchmarks |

### Confidence Statement

> These benchmarks provide **improved guidance** based on an **expanded sample** of 8 core Australian projects. They are appropriate for **early-stage planning** and **reasonableness testing**. The addition of 4 new projects has increased confidence, particularly for **medium-diameter (300-600mm)** pipelines. Project-specific cost estimation remains necessary for detailed business cases.
