# SLIDE 1: Purpose and Methodology

## Bulk Water Pipeline Cost Benchmarking
### Establishing Evidence-Based Cost Guidance for Infrastructure Planning

**Purpose**
- Develop defensible cost benchmarks for bulk water supply pipelines
- Support early-stage project scoping and business case development
- Enable reasonableness testing of cost estimates

**Methodology**
1. Comprehensive research of Australian bulk water pipeline projects (2019-2025)
2. Data collection from government announcements, budget papers, and official sources
3. Normalisation of costs to AUD 2024 using ABS construction cost indices
4. Statistical analysis and cost driver identification
5. Independent self-audit of research and analysis

**Scope Definition**
- Large-diameter pipelines (≥300mm) for municipal/agricultural bulk water supply
- Dam-to-treatment, scheme interconnections, regional supply
- Queensland priority, broader Australia coverage
- Excludes: urban reticulation, recycled water, desalination internal pipework

# SLIDE 4: Cost Driver Insights

## What Drives Bulk Water Pipeline Costs?

### Primary Cost Drivers (Ranked by Impact)

```
COST IMPACT SCALE
|========================================| 100%
|                                        |
|  1. DIAMETER                           |
|  [==============================]  60% |
|  Larger pipes = higher costs           |
|  +$2-4M/km per 500mm increase          |
|                                        |
|  2. TERRAIN / ACCESS                   |
|  [===================]  35%            |
|  Greenfield: +20-40% premium           |
|  Hilly terrain: +15-30%                |
|                                        |
|  3. SCOPE INCLUSIONS                   |
|  [============]  20%                   |
|  Treatment plants, reservoirs          |
|  Pump stations: +$0.5-1.5M/km          |
|                                        |
|  4. MARKET CONDITIONS                  |
|  [==========]  15%                     |
|  2020-24 escalation: 25%+              |
|  Labour & materials volatility         |
|========================================|
```

### Case Study: Terrain Impact

**Haughton Pipeline Comparison (Same 1,800mm Diameter)**

| Stage | Terrain | $/km | Difference |
|-------|---------|------|------------|
| Stage 1 | Existing corridor | $8.2M | Baseline |
| Stage 2 | Greenfield (new access) | $12.2-14.3M | **+48-74%** |

**Key Insight:** Greenfield construction requiring new access roads can increase costs by 50% or more, independent of pipeline size.

# SLIDE 5: Benchmarking Guidance for New Projects

## Recommended Cost Estimating Framework

### Step 1: Select Base Rate by Diameter

| Diameter | Base Rate ($/km) |
|----------|------------------|
| 300-450mm | $3.5M |
| 450-750mm | $5.5M |
| 750-1200mm | $9.0M |
| >1200mm | $10.0M |

### Step 2: Apply Adjustment Factors

| Factor | Adjustment |
|--------|------------|
| **Terrain** | |
| Existing corridor / flat | -15% |
| Rolling rural (base) | 0% |
| Hilly / challenging | +25% |
| Greenfield (new access) | +35% |
| **Scope** | |
| Pipeline only (base) | 0% |
| Including pump stations | +10% |
| Including treatment plant | +10% |
| **Location** | |
| Major regional (base) | 0% |
| Remote regional | +15% |

### Step 3: Add Allowances

| Allowance | Rate |
|-----------|------|
| Development costs | 8% of construction |
| Contingency | **25-30% minimum** |
| Escalation (if multi-year) | 5% per year |

### Example Calculation

**Scenario:** 50km pipeline, 600mm diameter, hilly terrain, regional location

| Component | Calculation | Amount |
|-----------|-------------|--------|
| Base rate | 50km × $5.5M | $275M |
| Terrain (+25%) | $275M × 1.25 | $344M |
| Development (8%) | $344M × 1.08 | $371M |
| Contingency (25%) | $371M × 1.25 | **$464M** |

# SLIDE 7: Recommended Next Steps

## Building a More Robust Evidence Base

### Immediate Actions

1. **Validate against current tenders**
   - Compare benchmarks to recent bid prices
   - Identify systematic over/under-estimation

2. **Expand geographic coverage**
   - Incorporate NSW, WA, SA projects as data becomes available
   - Test regional cost variations

3. **Improve cost breakdown data**
   - Seek detailed category splits (design, materials, labour, etc.)
   - Enable more granular benchmarking

### Ongoing Monitoring

4. **Track cost escalation**
   - Update normalisation indices annually
   - Monitor market conditions impact

5. **Include new projects**
   - Goldfields Pipeline Stage 1 (WA) - construction 2026
   - Other announced projects

### Data Quality Improvements

6. **Standardise definitions**
   - Pipeline-only vs inclusive scope
   - Consistent diameter classification

7. **Seek outturn data**
   - Update estimates with final costs
   - Understand budget vs actual variance

### Stakeholder Engagement

8. **Consult with delivery authorities**
   - Validate assumptions
   - Identify missing cost drivers

# SLIDE 8: Summary and Key Takeaways

## Bulk Water Pipeline Benchmarking: Key Messages

### What We Found

```
+----------------------------------------------------------+
|                                                          |
|  COST RANGE: $3.5M - $14.3M per kilometre               |
|              (AUD 2024, large diameter municipal)        |
|                                                          |
|  MEDIAN:     $8.6M per kilometre                        |
|                                                          |
|  KEY DRIVER: Diameter is primary determinant            |
|              Terrain/access is secondary driver          |
|                                                          |
|  CAUTION:    25%+ contingency essential in current      |
|              market conditions                           |
|                                                          |
+----------------------------------------------------------+
```

### How to Use This Data

| Do | Don't |
|----|-------|
| Use for early scoping | Rely on for tender prices |
| Apply adjustment factors | Use single point estimates |
| Include adequate contingency | Ignore terrain complexity |
| Document assumptions | Extrapolate beyond sample |

### Confidence Statement

> These benchmarks provide **preliminary guidance** based on a **limited sample** of recent Australian projects. They are appropriate for **early-stage planning** and **reasonableness testing** but should be supplemented with project-specific cost estimation for detailed business cases.
