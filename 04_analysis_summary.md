# Phase 5: Benchmarking Analysis Summary

**Analysis Date:** January 2026
**Data Currency:** AUD 2024 (Real)

---

## Executive Summary

This analysis examines 6 bulk water pipeline projects from Queensland and Victoria with construction activity between 2019-2025. The core sample of 4 large-diameter (≥600mm) municipal bulk supply pipelines provides the primary benchmarking basis, with 2 supplementary projects included for context.

**Key Finding:** Large-diameter bulk water pipeline costs in the 2019-2025 period range from **$3.5M to $14.3M per kilometre** (AUD 2024), with significant variation driven by diameter, terrain complexity, and scope inclusions.

### 4.2 Adjustment Factors

Apply the following adjustments to base rates:

| Condition | Adjustment |
|-----------|------------|
| **Terrain** | |
| - Flat/existing corridor | -10% to -20% |
| - Rolling rural | Base |
| - Hilly/mountainous | +15% to +30% |
| - Greenfield (new access required) | +20% to +40% |
| **Scope** | |
| - Pipeline only | Base |
| - With pump stations | +$0.5-1.5M/km |
| - With treatment plant | +5% to 15% of total |
| - With reservoirs | +$3-5M each |
| **Market** | |
| - Competitive market | -5% to -10% |
| - Constrained market | +10% to +20% |
| **Location** | |
| - SEQ/major regional | Base |
| - Remote regional | +10% to +25% |

## 7. Limitations & Caveats

### 7.1 Sample Limitations

| Limitation | Impact | Mitigation |
|------------|--------|------------|
| Small sample (n=4-6) | Low statistical power | Present ranges, not point estimates |
| Geographic concentration (QLD/VIC) | May not generalise | Note regional specificity |
| Time period volatility | Costs may not persist | Document market conditions |
| Scope variation | Impairs comparability | Adjust for major inclusions |

### 7.2 Confidence Levels

| Metric | Confidence | Basis |
|--------|------------|-------|
| $/km range | **Moderate-High** | Multiple verified projects |
| Diameter impact | **Moderate** | Clear trend, limited points |
| Terrain impact | **Low-Moderate** | Limited comparative data |
| Development % | **Low** | Single verified data point |

### 7.3 Recommended Use

This benchmarking data is appropriate for:
- ✅ Early-stage project scoping
- ✅ Order-of-magnitude estimates
- ✅ Business case reasonableness checks
- ⚠️ Detailed cost planning (with adjustment)
- ❌ Tender evaluation (insufficient precision)
